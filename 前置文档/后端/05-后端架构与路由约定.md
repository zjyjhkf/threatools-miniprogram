## 1. 设计原则

1. **薄 Controller，厚 Service**：路由函数只做参数解析、依赖注入、调用 Service、返回 schema；业务规则全部在 Service。
2. **一个入口一个响应包**：所有成功/失败都经统一 envelope，绝不让 FastAPI 默认的 `{"detail": ...}` 泄漏到客户端。
3. **异步到底**：DB、HTTP 外呼（微信）全部 async，禁止在 async 函数里调用同步阻塞库。
4. **显式依赖**：`db`、`current_user`、`pagination` 一律通过 `Depends` 注入，不写全局变量。
5. **可定位**：每个请求有 `request_id`，贯穿日志、响应头、响应体。
6. **契约优先**：接口路径/字段以 `01-接口文档.md` 为准，实现不得"顺手改"。

## 3. 分层职责

| 层 | 可以做 | 不可以做 |
|---|---|---|
| Router | 参数校验（Query/Body）、依赖注入、调 Service、拼响应 schema | 写 SQL、写业务分支、直接 `await db.execute` |
| Service | 业务规则、多表事务、调用 repo、抛业务异常、写审计 | 解析 HTTP 细节、拼 `JSONResponse` |
| Repository | 单表/简单 join 查询、分页、计数、批量写 | 抛业务异常、做权限判断 |
| Model | 字段、关系、索引声明 | 业务方法（除简单 property） |
| Schema | 入参校验、出参序列化、camel 别名 | 访问数据库 |

## 4. 路由约定

| 项 | 约定 |
|---|---|
| 前缀 | 全部挂在 `/api/v1`；健康检查例外，直接 `/healthz` |
| 版本 | 路径版本；不兼容变更开 `/api/v2` |
| 命名 | 资源名复数（`/posts`、`/topics`）；动作用子路径（`/posts/{id}/like`） |
| 方法 | GET 查询、POST 创建/动作、PUT 全量更新、PATCH 部分更新、DELETE 删除 |
| 参数 | 路径参数用 `{id}`；查询参数 snake_case（`page`、`size`、`cursor`、`type`）；请求体用 schema |
| 状态码 | 业务错误也用 200 + `code`（除 401/403/404/429/500 用对应 HTTP 状态）；便于前端统一处理 |
| 路由函数 | `async def`，返回 `ResponseModel`，不返回 dict |
| tag | 每个文件一个 tag（`auth`、`users`、`posts`…），用于 `/docs` 分组 |
| 权限 | 免鉴权接口不加依赖；"可选"用 `optional_user`；"必须"用 `current_user` |

## 6. 统一响应与异常

### 6.1 响应包

```python
# app/core/response.py
from typing import Generic, TypeVar, Any
from pydantic import BaseModel, ConfigDict
from pydantic.alias_generators import to_camel

T = TypeVar("T")

class CamelModel(BaseModel):
    model_config = ConfigDict(
        alias_generator=to_camel,
        populate_by_name=True,
        from_attributes=True,
    )

class Envelope(CamelModel, Generic[T]):
    code: int = 0
    message: str = "ok"
    data: T | None = None
    request_id: str = ""

def ok(data: Any = None, request_id: str = "") -> dict:
    return {"code": 0, "message": "ok", "data": data, "requestId": request_id}
```

> 输出时统一 `model_dump(by_alias=True)`，保证 camelCase；**不要**在路由里手工拼 dict 以外的键。

### 6.2 异常体系

```python
# app/core/errors.py
class BizError(Exception):
    code: int = 40001
    http_status: int = 200
    message: str = "请求失败"
    def __init__(self, message: str | None = None, code: int | None = None):
        if message: self.message = message
        if code: self.code = code

class NotFound(BizError):  code, http_status, message = 40401, 404, "内容不存在或已删除"
class Forbidden(BizError): code, http_status, message = 40301, 403, "没有权限"
class Unauthorized(BizError): code, http_status, message = 40101, 401, "登录已失效"
class Conflict(BizError): code, http_status, message = 40901, 409, "请勿重复操作"
class RateLimited(BizError): code, http_status, message = 42901, 429, "操作太频繁，请稍后再试"
class ValidationBiz(BizError): code, http_status, message = 42201, 422, "参数不合法"
```

| 异常 | 处理 |
|---|---|
| `BizError` 子类 | 按 `http_status` + envelope 返回 |
| `RequestValidationError`（Pydantic） | 转 `40001`，`message` 取首个字段错误的中文描述 |
| `HTTPException` | 转对应 code（401→40101 等） |
| 未捕获 `Exception` | 记 `ERROR` 日志（含堆栈 + request_id），返回 `50000`「服务异常，请稍后重试」 |

**硬规则**：任何响应都带 `requestId`；不得把 Python 堆栈返回给客户端。

### 6.3 request_id 中间件

```python
# app/core/request_id.py
import uuid
from starlette.middleware.base import BaseHTTPMiddleware
from contextvars import ContextVar

request_id_ctx: ContextVar[str] = ContextVar("request_id", default="")

class RequestIdMiddleware(BaseHTTPMiddleware):
    async def dispatch(self, request, call_next):
        rid = request.headers.get("X-Request-Id") or uuid.uuid4().hex[:16]
        token = request_id_ctx.set(rid)
        try:
            response = await call_next(request)
        finally:
            request_id_ctx.reset(token)
        response.headers["X-Request-Id"] = rid
        return response
```

**优先级**：客户端传入 `X-Request-Id` > Nginx `$request_id` > 服务端生成。**回写响应体**由路由层从 `request_id_ctx` 取值。

## 7. 依赖注入

```python
# app/api/deps.py
from typing import Annotated, AsyncGenerator
from fastapi import Depends, Header
from sqlalchemy.ext.asyncio import AsyncSession

from app.db.session import async_session_factory
from app.core.security import decode_token
from app.core.errors import Unauthorized
from app.repositories.user_repo import UserRepo

async def get_db() -> AsyncGenerator[AsyncSession, None]:
    async with async_session_factory() as session:
        try:
            yield session
            await session.commit()
        except Exception:
            await session.rollback()
            raise

DbDep = Annotated[AsyncSession, Depends(get_db)]

def _bearer(authorization: str | None) -> str | None:
    if not authorization or not authorization.lower().startswith("bearer "):
        return None
    return authorization.split(" ", 1)[1].strip()

async def optional_user(db: DbDep, authorization: str | None = Header(default=None)):
    token = _bearer(authorization)
    if not token:
        return None
    try:
        payload = decode_token(token)
    except Exception:
        return None
    return await UserRepo(db).get_active(int(payload["sub"]))

async def current_user(user=Depends(optional_user)):
    if user is None:
        raise Unauthorized()
    return user

CurrentUser = Annotated[object, Depends(current_user)]
OptionalUser = Annotated[object | None, Depends(optional_user)]
```

| 依赖 | 用途 |
|---|---|
| `DbDep` | 会话 + 自动提交/回滚 |
| `OptionalUser` | 免鉴权但需要个人化字段的接口 |
| `CurrentUser` | 必须登录 |
| `CurrentAdmin` | 管理端（1.1），校验 `aud=admin` 与 `role` |
| `Pagination` | 解析 `page/size` 或 `cursor/size` |

## 8. 分页

```python
# app/core/pagination.py
class PageParams(BaseModel):
    page: int = 1
    size: int = 10
    def __init__(self, **data):
        super().__init__(**data)
        self.page = max(1, self.page)
        self.size = min(max(1, self.size), 30)

class CursorParams(BaseModel):
    cursor: str = ""
    size: int = 10
    def __init__(self, **data):
        super().__init__(**data)
        self.size = min(max(1, self.size), 30)
```

| 分页 | 用于 | 返回 |
|---|---|---|
| 游标 | feed、comments、topic posts | `{list, nextCursor, hasMore}` |
| 页码 | topics、courses、favorites、search、user posts | `{list, total, page, size, hasMore}` |

**实现要点**
- 游标用 `WHERE id < :cursor`（id 倒序）；`cursor` 非法时按首页处理，不报错。
- `hasMore` 用"多取一条"判断：`LIMIT size+1`，多出则 `hasMore=true` 并丢弃。
- 计数用 `SELECT COUNT(*)` 只对页码分页执行；游标分页不返回 `total`（性能）。

## 9. 事务与一致性

| 场景 | 事务写法 |
|---|---|
| 发布帖子 | 一个事务：`posts` 插入 → `post_images` 批量插入 → `post_topics` 批量插入 → `topics.post_count +1` |
| 删除帖子 | 一个事务：`posts` 软删 → 删除 `likes/collections`（`target_type='post'`）→ `post_topics` 删除 → `topics.post_count -1` |
| 点赞 | 一个事务：`likes` 插入（唯一键冲突→视为已赞）→ `posts.like_count +1` |
| 删除评论 | 一个事务：`comments` 软删（含子回复）→ `posts.comment_count - 数量` |
| 上传 | 先落盘 → 再写 `upload_files`（失败则删文件） |

**规则**
1. `get_db` 依赖里统一 `commit/rollback`，Service 内**不显式 commit**（除长事务脚本）。
2. 计数更新用 `UPDATE ... SET x = x + 1`，禁止 `SELECT` 后 `UPDATE` 绝对值。
3. 删除前先校验归属（`user_id == current_user.id`），否则 `Forbidden`。
4. 任何写操作都要幂等或去重（ADR-005 后果）。

## 10. Schema 约定

```python
# app/schemas/post.py
from datetime import datetime
from app.core.response import CamelModel

class AuthorOut(CamelModel):
    id: str
    nickname: str
    avatar: str

class PostOut(CamelModel):
    id: str
    author: AuthorOut
    followed: bool = False
    content: str
    images: list[ImageOut] = []
    topics: list[TopicBriefOut] = []
    visibility: str = "public"
    status: str = "published"
    like_count: int = 0
    comment_count: int = 0
    collect_count: int = 0
    liked: bool = False
    collected: bool = False
    is_author: bool = False
    created_at: datetime

    @field_serializer("created_at")
    def _fmt(self, v: datetime) -> str:
        return v.strftime("%Y-%m-%d %H:%M:%S")
```

| 规则 | 说明 |
|---|---|
| ID | `str` 类型 + `field_validator` 或 model 层 `serialize` 转字符串 |
| 时间 | 统一 `field_serializer` 输出 `YYYY-MM-DD HH:mm:ss` |
| 可选 | 用「类型与 None 的联合」新写法（Pydantic v2 支持），不用 `Optional[X]` |
| 默认值 | 列表用 `[]`（Pydantic v2 会拷贝，安全） |
| 入参 | `XxxCreate` / `XxxUpdate` 命名；`Update` 全字段可选 |
| 出参 | `XxxOut`；**禁止直接把 ORM 对象返回给前端**（避免泄漏 `deleted`、`open_id`） |
| 白名单 | 产品/用户出参显式列字段，绝不 `SELECT *` 后整对象 dump |

## 11. 业务层约定

| 项 | 约定 |
|---|---|
| 方法命名 | `get_xxx / list_xxx / create_xxx / update_xxx / delete_xxx / toggle_xxx` |
| 参数 | 只传必要参数（`user_id` 而非整个 user 对象），便于测试 |
| 异常 | 抛 `NotFound/Forbidden/Conflict/ValidationBiz`，不返回 `None` 让上层猜 |
| 敏感词 | `moderation.check(text)`，命中抛 `ValidationBiz("内容包含不适合发布的信息")` |
| 限流 | 在 router 层用 `Depends(rate_limit("post", 5, 3600))`，key 为 `user:{id}` |
| 计数器 | `reconcile.py` 每日 02:00 修正漂移，幂等 |
| 日志 | Service 只记业务事件（`post_created post_id=...`），不记请求细节 |

| 项 | 规则 |
|---|---|
| 格式化 | `ruff format`（line-length 100） |
| Lint | `ruff check`（`E,F,I,UP,B,ASYNC`） |
| 类型 | `mypy --strict` 对 `app/` 全量；最少对 `services/` 与 `core/` |
| 导入 | 绝对导入 `from app.xxx import`；`isort` 由 ruff 统一 |
| 注释 | 公开函数 docstring；复杂 SQL 用 `-- 说明` |
| 禁止 | `time.sleep`、同步 `requests`、裸 `print`、`except: pass` |
| 提交 | `feat(posts): ...`、`fix(auth): ...`、`refactor(repo): ...` |

```toml

[tool.ruff]
line-length = 100
target-version = "py311"

[tool.ruff.lint]
select = ["E", "F", "I", "UP", "B", "ASYNC", "S"]

[tool.mypy]
python_version = "3.11"
strict = true
```

## 15. Alembic 工作流

| 步骤 | 命令 |
|---|---|
| 1. 改模型 | 修改 `app/models/*.py` |
| 2. 生成迁移 | `alembic revision --autogenerate -m "add xxx"` |
| 3. **人工检查** | 确认没有意外 drop、索引名正确、`downgrade` 可逆 |
| 4. 本地升级 | `alembic upgrade head` |
| 5. 测试 | 跑 `pytest` |
| 6. 上线 | 备份 → `upgrade head` → 健康检查 |

**规则**：迁移文件必须提交；命名 `0003_add_hidden_status.py`；禁止手改已上线的迁移。

## 16. 安全清单

- [ ] `JWT_SECRET` 非默认值，≥32 字节
- [ ] `docs_url` 在 prod 关闭（或加 admin 鉴权）
- [ ] 所有写接口校验归属（他人资源 403）
- [ ] 上传用 Pillow 校验真实格式，拒绝 SVG
- [ ] SQL 全参数化（SQLAlchemy 表达式，禁止 f-string 拼 SQL）
- [ ] CORS 生产只允许管理端域名
- [ ] 日志脱敏：不打印 token、`open_id`、`session_key`
- [ ] 限流开启（`RATE_LIMIT_ENABLE=true`）
- [ ] 数据库账号仅授权 `jianheng` 库、非 root
- [ ] 错误响应不含堆栈与 SQL

## 17. 常见实现坑

| # | 坑 | 正确做法 |
|---|---|---|
| 1 | 路由里 `return {"code":0,...}` 手工拼，漏 requestId | 用 `ok()` 统一包装 |
| 2 | Pydantic 未设 `by_alias=True`，前端拿到 snake_case | 统一 `CamelModel` + 全局 `response_model_by_alias=True` |
| 3 | 直接把 ORM 对象返回，泄漏 `open_id` | 显式 `XxxOut` 白名单 |
| 4 | `async` 里用同步 `mysqlclient` | 必须 `asyncmy` + `create_async_engine` |
| 5 | 忘记 `await session.commit()`（依赖里已统一） | 不要在 Service 里再 commit |
| 6 | 点赞计数并发放大 | `UPDATE ... SET x = x + 1` + 唯一键兜底 |
| 7 | 游标分页用 `offset` | 用 `id < cursor` |
| 8 | 时间直接返回 `datetime` 对象 | `field_serializer` 格式化 |
| 9 | 上传只信 `content_type` | Pillow 校验 + 大小检查 |
| 10 | 中文搜索大小写/全半角问题 | 统一 `strip()` + `utf8mb4_general_ci`（不区分大小写） |
