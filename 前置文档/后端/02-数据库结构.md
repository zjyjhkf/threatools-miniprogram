# 健衡运动社区 · 1.0 数据库结构

| 项 | 内容 |
|---|---|
| 文档编号 | JH-BE-DB-1.0 |
| 版本 | 1.0 |
| 数据库 | MySQL 8.0，库名 `jianheng`，字符集 `utf8mb4` / `utf8mb4_general_ci` |
| 时区 | 服务器与连接串统一 `Asia/Shanghai` |
| 表 | **17 张**（14 业务 + 3 支撑与预留） |
| 迁移 | Alembic，单链 `base → 0001_init → 0002_indexes` |
| 关联 | `03-数据库设计决策记录.md`（为什么）、`01-接口文档.md`（怎么用） |

---

## 1. 约定

| 项 | 规则 |
|---|---|
| 引擎 | InnoDB |
| 主键 | `id BIGINT UNSIGNED AUTO_INCREMENT`，对外输出字符串 |
| 时间 | `DATETIME(3)`，`created_at DEFAULT CURRENT_TIMESTAMP(3)`，`updated_at ... ON UPDATE` |
| 软删 | 内容类用 `deleted TINYINT(1)` + `status`；关系类（点赞/收藏/关注）用**硬删** |
| 外键 | **不建物理外键**，只建索引；一致性由应用层事务保证 |
| 枚举 | `VARCHAR(20)` 存字符串，注释里列出取值；不用 MySQL `ENUM`（改值要 DDL） |
| 金额 | 1.0 无金额字段 |
| 计数 | 冗余计数列（`like_count` 等），事务内 `+1/-1`，每日对账 |
| 命名 | 表 `jh_` 前缀复数、字段 snake_case、索引 `idx_`、唯一 `uk_` |

---

## 2. ER 图

```
users 1───1 body_profiles
  │  │  │
  │  │  └──n posts ──n── post_images
  │  │        │
  │  │        └──n── post_topics ──n── topics
  │  ├──n comments ──n── likes(comment)
  │  ├──n likes(post|comment)
  │  ├──n collections(post|course|product|topic)
  │  ├──n follows(follower → followee)
  │  └──n upload_files
courses 1──n chapters
products 1──n product_images
admin_users（独立体系，无外键）
track_events（无外键，弱关联 user_id）
```

## 3. 表结构

### 3.1 `users`

| 字段 | 类型 | 空 | 默认 | 说明 |
|---|---|---|---|---|
| id | BIGINT UNSIGNED PK | 否 | AI | — |
| open_id | VARCHAR(64) | 否 | — | 微信 openid，唯一 |
| union_id | VARCHAR(64) | 是 | NULL | 预留 |
| nickname | VARCHAR(32) | 是 | NULL | 2–20 字 |
| avatar | VARCHAR(512) | 是 | NULL | 头像 URL |
| gender | VARCHAR(10) | 否 | 'secret' | male/female/secret |
| birthday | DATE | 是 | NULL | 年龄 ≥12 |
| city | VARCHAR(64) | 是 | NULL | `省/市` |
| bio | VARCHAR(100) | 是 | NULL | ≤30 字（应用层限） |
| wechat_id | VARCHAR(64) | 是 | NULL | 展示用 |
| profile_visibility | VARCHAR(20) | 否 | 'self' | self/followers/public |
| role | VARCHAR(20) | 否 | 'user' | user/admin（1.0 仅 user） |
| status | TINYINT | 否 | 1 | 1 正常 0 禁用 |
| last_login_at | DATETIME(3) | 是 | NULL | — |
| created_at / updated_at | DATETIME(3) | 否 | NOW | `created_at` 用于「已加入 N 天」 |

索引：`UNIQUE uk_openid(open_id)`、`idx_status(status)`。

### 3.2 `body_profiles`

| 字段 | 类型 | 空 | 说明 |
|---|---|---|---|
| id | BIGINT UNSIGNED PK | 否 | — |
| user_id | BIGINT UNSIGNED | 否 | 唯一 |
| height | SMALLINT UNSIGNED | 是 | 100–250 cm |
| weight | DECIMAL(5,1) | 是 | 30.0–200.0 kg |
| goals | JSON | 是 | `["recovery","posture"]`，1–3 项 |
| frequency | VARCHAR(20) | 是 | 1-2/3-4/5+/irregular |
| level | VARCHAR(20) | 是 | beginner/intermediate/advanced |
| focus_parts | JSON | 是 | ≤6 项 |
| injuries | VARCHAR(200) | 是 | ≤100 字 |
| allow_public | TINYINT(1) | 否 | 默认 0 |
| created_at / updated_at | DATETIME(3) | 否 | — |

索引：`UNIQUE uk_user(user_id)`。

### 3.3 `posts`

| 字段 | 类型 | 空 | 默认 | 说明 |
|---|---|---|---|---|
| id | BIGINT UNSIGNED PK | 否 | AI | — |
| user_id | BIGINT UNSIGNED | 否 | — | 作者 |
| content | VARCHAR(1000) | 否 | '' | ≤500 字 |
| visibility | VARCHAR(20) | 否 | 'public' | public/followers |
| cover_image | VARCHAR(512) | 是 | NULL | 第 1 张图，列表用 |
| image_count | TINYINT UNSIGNED | 否 | 0 | 0–9 |
| status | VARCHAR(20) | 否 | 'published' | published/hidden/reviewing/deleted |
| topic_id | BIGINT UNSIGNED | 是 | NULL | 主话题（冗余，便于话题流） |
| like_count / comment_count / collect_count | INT UNSIGNED | 否 | 0 | 冗余计数 |
| deleted | TINYINT(1) | 否 | 0 | 软删 |
| created_at / updated_at | DATETIME(3) | 否 | NOW | — |

索引：`idx_status_created(status, created_at DESC)`、`idx_user(user_id, created_at DESC)`、`idx_topic(topic_id, created_at DESC)`。

### 3.4 `post_images`

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT PK | — |
| post_id | BIGINT | 索引 |
| url | VARCHAR(512) | CDN 地址 |
| width / height | SMALLINT UNSIGNED | 原图尺寸（前端算比例） |
| sort | TINYINT UNSIGNED | 0–8 |

索引：`idx_post(post_id, sort)`。

### 3.5 `topics`

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT PK | — |
| name | VARCHAR(40) | 唯一，不含 `#` |
| description | VARCHAR(120) | ≤60 字 |
| post_count / user_count | INT UNSIGNED | 冗余 |
| is_hot | TINYINT(1) | 是否进热门 |
| sort | INT | 热门权重，越大越前 |
| created_at / updated_at | DATETIME(3) | — |

索引：`UNIQUE uk_name(name)`、`idx_hot(is_hot, sort DESC)`。

### 3.6 `post_topics`

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT PK | — |
| post_id / topic_id | BIGINT | — |

索引：`UNIQUE uk_post_topic(post_id, topic_id)`、`idx_topic(topic_id)`。

### 3.7 `comments`

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT PK | — |
| post_id | BIGINT | — |
| user_id | BIGINT | 评论者 |
| parent_id | BIGINT | 0 = 一级；否则为被回复评论（只一层） |
| reply_to_user_id | BIGINT | 被回复者 |
| content | VARCHAR(400) | ≤200 字 |
| like_count | INT UNSIGNED | — |
| status | VARCHAR(20) | normal/deleted |
| created_at | DATETIME(3) | — |

索引：`idx_post(post_id, created_at DESC)`、`idx_parent(parent_id)`、`idx_user(user_id)`。

### 3.8 `likes`

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT PK | — |
| user_id | BIGINT | — |
| target_type | VARCHAR(10) | post/comment |
| target_id | BIGINT | — |
| created_at | DATETIME(3) | — |

索引：`UNIQUE uk_user_target(user_id, target_type, target_id)`、`idx_target(target_type, target_id)`。

### 3.9 `collections`

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT PK | — |
| user_id | BIGINT | — |
| target_type | VARCHAR(10) | post/course/product/topic |
| target_id | BIGINT | — |
| created_at | DATETIME(3) | — |

索引：`UNIQUE uk_user_target(user_id, target_type, target_id)`、`idx_user_type(user_id, target_type, created_at DESC)`。

### 3.10 `follows`

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT PK | — |
| follower_id | BIGINT | 关注者 |
| followee_id | BIGINT | 被关注者 |
| created_at | DATETIME(3) | — |

索引：`UNIQUE uk_follow(follower_id, followee_id)`、`idx_followee(followee_id)`。

### 3.11 `courses`

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT PK | — |
| title | VARCHAR(60) | ≤30 字 |
| cover | VARCHAR(512) | 16:9 列表封面 |
| video_cover | VARCHAR(512) | 详情大图 |
| duration | INT UNSIGNED | 秒 |
| action_count | SMALLINT UNSIGNED | 动作数 |
| difficulty | VARCHAR(20) | beginner/middle/advanced |
| category | VARCHAR(20) | rehab/recovery/posture/stretch |
| coach_name / coach_avatar / coach_title | VARCHAR | 教练信息 |
| intro | TEXT | 课程介绍 |
| suitable_for | JSON | 3 个标签 |
| learn_count / collect_count | INT UNSIGNED | 冗余 |
| is_main | TINYINT(1) | 本周主推 |
| sort | INT | — |
| status | TINYINT | 1 上架 0 下架 |
| created_at / updated_at | DATETIME(3) | — |

索引：`idx_category(category, sort)`、`idx_main(is_main)`。

### 3.12 `chapters`

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT PK | — |
| course_id | BIGINT | — |
| idx | SMALLINT UNSIGNED | 第几节，从 1 开始 |
| title | VARCHAR(60) | 章节名 |
| duration | INT UNSIGNED | 秒 |
| video_url | VARCHAR(512) | mp4 地址 |
| locked | TINYINT(1) | 0.1/1.0 全 0 |

索引：`idx_course(course_id, idx)`。

### 3.13 `products`

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT PK | — |
| name | VARCHAR(60) | 产品名 |
| model | VARCHAR(40) | 型号 |
| category | VARCHAR(20) | rehab/recovery/portable |
| tagline | VARCHAR(60) | ≤20 字 |
| tags | JSON | `["热门","康复治疗"]` |
| features | JSON | `[{icon,title,desc}]` ×3 |
| specs | JSON | `[{label,value}]` ×9 |
| suitable_for | JSON | 3 项 |
| video_cover / video_url | VARCHAR(512) | 使用视频 |
| collect_count | INT UNSIGNED | — |
| sort | INT | — |
| status | TINYINT | 1 上架 0 下架 |
| created_at / updated_at | DATETIME(3) | — |

索引：`idx_category(category, sort)`。

### 3.14 `product_images`

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT PK | — |
| product_id | BIGINT | — |
| url | VARCHAR(512) | 1:1 图 |
| sort | TINYINT UNSIGNED | 0–3 |

索引：`idx_product(product_id, sort)`。

### 3.15 `track_events`（支撑表）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT PK | — |
| user_id | BIGINT | 可空（游客事件） |
| event | VARCHAR(40) | 事件名白名单 |
| props | JSON | ≤2KB |
| page | VARCHAR(80) | 页面路径 |
| ip | VARCHAR(45) | 节流用，已脱敏存储 |

### 3.17 `admin_users`（预留）

## 4. 完整 DDL

```sql
CREATE DATABASE IF NOT EXISTS `jianheng`
  DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
USE `jianheng`;

CREATE TABLE `users` (
  `id` BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  `open_id` VARCHAR(64) NOT NULL,
  `union_id` VARCHAR(64) DEFAULT NULL,
  `nickname` VARCHAR(32) DEFAULT NULL,
  `avatar` VARCHAR(512) DEFAULT NULL,
  `gender` VARCHAR(10) NOT NULL DEFAULT 'secret',
  `birthday` DATE DEFAULT NULL,
  `city` VARCHAR(64) DEFAULT NULL,
  `bio` VARCHAR(100) DEFAULT NULL,
  `wechat_id` VARCHAR(64) DEFAULT NULL,
  `profile_visibility` VARCHAR(20) NOT NULL DEFAULT 'self',
  `role` VARCHAR(20) NOT NULL DEFAULT 'user',
  `status` TINYINT NOT NULL DEFAULT 1,
  `last_login_at` DATETIME(3) DEFAULT NULL,
  `created_at` DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3),
  `updated_at` DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3) ON UPDATE CURRENT_TIMESTAMP(3),
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_openid` (`open_id`),
  KEY `idx_status` (`status`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='用户';

CREATE TABLE `body_profiles` (
  `id` BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  `user_id` BIGINT UNSIGNED NOT NULL,
  `height` SMALLINT UNSIGNED DEFAULT NULL,
  `weight` DECIMAL(5,1) DEFAULT NULL,
  `goals` JSON DEFAULT NULL,
  `frequency` VARCHAR(20) DEFAULT NULL,
  `level` VARCHAR(20) DEFAULT NULL,
  `focus_parts` JSON DEFAULT NULL,
  `injuries` VARCHAR(200) DEFAULT NULL,
  `allow_public` TINYINT(1) NOT NULL DEFAULT 0,
  `created_at` DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3),
  `updated_at` DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3) ON UPDATE CURRENT_TIMESTAMP(3),
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_user` (`user_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='身体档案';

CREATE TABLE `posts` (
  `id` BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  `user_id` BIGINT UNSIGNED NOT NULL,
  `content` VARCHAR(1000) NOT NULL DEFAULT '',
  `visibility` VARCHAR(20) NOT NULL DEFAULT 'public',
  `cover_image` VARCHAR(512) DEFAULT NULL,
  `image_count` TINYINT UNSIGNED NOT NULL DEFAULT 0,
  `status` VARCHAR(20) NOT NULL DEFAULT 'published',
  `topic_id` BIGINT UNSIGNED DEFAULT NULL,
  `like_count` INT UNSIGNED NOT NULL DEFAULT 0,
  `comment_count` INT UNSIGNED NOT NULL DEFAULT 0,
  `collect_count` INT UNSIGNED NOT NULL DEFAULT 0,
  `deleted` TINYINT(1) NOT NULL DEFAULT 0,
  `created_at` DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3),
  `updated_at` DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3) ON UPDATE CURRENT_TIMESTAMP(3),
  PRIMARY KEY (`id`),
  KEY `idx_status_created` (`status`, `created_at` DESC),
  KEY `idx_user` (`user_id`, `created_at` DESC),
  KEY `idx_topic` (`topic_id`, `created_at` DESC)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='帖子';

CREATE TABLE `post_images` (
  `id` BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  `post_id` BIGINT UNSIGNED NOT NULL,
  `url` VARCHAR(512) NOT NULL,
  `width` SMALLINT UNSIGNED DEFAULT NULL,
  `height` SMALLINT UNSIGNED DEFAULT NULL,
  `sort` TINYINT UNSIGNED NOT NULL DEFAULT 0,
  PRIMARY KEY (`id`),
  KEY `idx_post` (`post_id`, `sort`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='帖子图片';

CREATE TABLE `topics` (
  `id` BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  `name` VARCHAR(40) NOT NULL,
  `description` VARCHAR(120) DEFAULT NULL,
  `post_count` INT UNSIGNED NOT NULL DEFAULT 0,
  `user_count` INT UNSIGNED NOT NULL DEFAULT 0,
  `is_hot` TINYINT(1) NOT NULL DEFAULT 0,
  `sort` INT NOT NULL DEFAULT 0,
  `created_at` DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3),
  `updated_at` DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3) ON UPDATE CURRENT_TIMESTAMP(3),
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_name` (`name`),
  KEY `idx_hot` (`is_hot`, `sort` DESC)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='话题';

CREATE TABLE `post_topics` (
  `id` BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  `post_id` BIGINT UNSIGNED NOT NULL,
  `topic_id` BIGINT UNSIGNED NOT NULL,
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_post_topic` (`post_id`, `topic_id`),
  KEY `idx_topic` (`topic_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='帖子-话题';

CREATE TABLE `comments` (
  `id` BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  `post_id` BIGINT UNSIGNED NOT NULL,
  `user_id` BIGINT UNSIGNED NOT NULL,
  `parent_id` BIGINT UNSIGNED NOT NULL DEFAULT 0,
  `reply_to_user_id` BIGINT UNSIGNED DEFAULT NULL,
  `content` VARCHAR(400) NOT NULL,
  `like_count` INT UNSIGNED NOT NULL DEFAULT 0,
  `status` VARCHAR(20) NOT NULL DEFAULT 'normal',
  `created_at` DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3),
  PRIMARY KEY (`id`),
  KEY `idx_post` (`post_id`, `created_at` DESC),
  KEY `idx_parent` (`parent_id`),
  KEY `idx_user` (`user_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='评论';

CREATE TABLE `likes` (
  `id` BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  `user_id` BIGINT UNSIGNED NOT NULL,
  `target_type` VARCHAR(10) NOT NULL,
  `target_id` BIGINT UNSIGNED NOT NULL,
  `created_at` DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3),
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_user_target` (`user_id`, `target_type`, `target_id`),
  KEY `idx_target` (`target_type`, `target_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='点赞';

CREATE TABLE `collections` (
  `id` BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  `user_id` BIGINT UNSIGNED NOT NULL,
  `target_type` VARCHAR(10) NOT NULL,
  `target_id` BIGINT UNSIGNED NOT NULL,
  `created_at` DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3),
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_user_target` (`user_id`, `target_type`, `target_id`),
  KEY `idx_user_type` (`user_id`, `target_type`, `created_at` DESC)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='收藏';

CREATE TABLE `follows` (
  `id` BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  `follower_id` BIGINT UNSIGNED NOT NULL,
  `followee_id` BIGINT UNSIGNED NOT NULL,
  `created_at` DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3),
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_follow` (`follower_id`, `followee_id`),
  KEY `idx_followee` (`followee_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='关注';

CREATE TABLE `courses` (
  `id` BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  `title` VARCHAR(60) NOT NULL,
  `cover` VARCHAR(512) NOT NULL,
  `video_cover` VARCHAR(512) DEFAULT NULL,
  `duration` INT UNSIGNED NOT NULL DEFAULT 0,
  `action_count` SMALLINT UNSIGNED NOT NULL DEFAULT 0,
  `difficulty` VARCHAR(20) NOT NULL DEFAULT 'beginner',
  `category` VARCHAR(20) NOT NULL DEFAULT 'rehab',
  `coach_name` VARCHAR(32) DEFAULT NULL,
  `coach_avatar` VARCHAR(512) DEFAULT NULL,
  `coach_title` VARCHAR(64) DEFAULT NULL,
  `intro` TEXT,
  `suitable_for` JSON DEFAULT NULL,
  `learn_count` INT UNSIGNED NOT NULL DEFAULT 0,
  `collect_count` INT UNSIGNED NOT NULL DEFAULT 0,
  `is_main` TINYINT(1) NOT NULL DEFAULT 0,
  `sort` INT NOT NULL DEFAULT 0,
  `status` TINYINT NOT NULL DEFAULT 1,
  `created_at` DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3),
  `updated_at` DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3) ON UPDATE CURRENT_TIMESTAMP(3),
  PRIMARY KEY (`id`),
  KEY `idx_category` (`category`, `sort`),
  KEY `idx_main` (`is_main`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='课程';

CREATE TABLE `chapters` (
  `id` BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  `course_id` BIGINT UNSIGNED NOT NULL,
  `idx` SMALLINT UNSIGNED NOT NULL,
  `title` VARCHAR(60) NOT NULL,
  `duration` INT UNSIGNED NOT NULL DEFAULT 0,
  `video_url` VARCHAR(512) DEFAULT NULL,
  `locked` TINYINT(1) NOT NULL DEFAULT 0,
  PRIMARY KEY (`id`),
  KEY `idx_course` (`course_id`, `idx`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='课程章节';

CREATE TABLE `products` (
  `id` BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  `name` VARCHAR(60) NOT NULL,
  `model` VARCHAR(40) DEFAULT NULL,
  `category` VARCHAR(20) NOT NULL DEFAULT 'rehab',
  `tagline` VARCHAR(60) DEFAULT NULL,
  `tags` JSON DEFAULT NULL,
  `features` JSON DEFAULT NULL,
  `specs` JSON DEFAULT NULL,
  `suitable_for` JSON DEFAULT NULL,
  `video_cover` VARCHAR(512) DEFAULT NULL,
  `video_url` VARCHAR(512) DEFAULT NULL,
  `collect_count` INT UNSIGNED NOT NULL DEFAULT 0,
  `sort` INT NOT NULL DEFAULT 0,
  `status` TINYINT NOT NULL DEFAULT 1,
  `created_at` DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3),
  `updated_at` DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3) ON UPDATE CURRENT_TIMESTAMP(3),
  PRIMARY KEY (`id`),
  KEY `idx_category` (`category`, `sort`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='产品（无价格字段）';

CREATE TABLE `product_images` (
  `id` BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  `product_id` BIGINT UNSIGNED NOT NULL,
  `url` VARCHAR(512) NOT NULL,
  `sort` TINYINT UNSIGNED NOT NULL DEFAULT 0,
  PRIMARY KEY (`id`),
  KEY `idx_product` (`product_id`, `sort`)

CREATE TABLE `track_events` (
```

## 5. SQLAlchemy 模型示例

```python
# app/models/post.py
from datetime import datetime
from sqlalchemy import BigInteger, String, Integer, SmallInteger, DateTime, Index, func
from sqlalchemy.dialects.mysql import TINYINT
from sqlalchemy.orm import Mapped, mapped_column, relationship
from app.db.base import Base

class Post(Base):
    __tablename__ = "posts"
    __table_args__ = (
        Index("idx_status_created", "status", "created_at"),
        Index("idx_user", "user_id", "created_at"),
    )

    id: Mapped[int] = mapped_column(BigInteger, primary_key=True, autoincrement=True)
    user_id: Mapped[int] = mapped_column(BigInteger, nullable=False, index=True)
    content: Mapped[str] = mapped_column(String(1000), nullable=False, default="")
    visibility: Mapped[str] = mapped_column(String(20), nullable=False, default="public")
    cover_image: Mapped[str | None] = mapped_column(String(512))
    image_count: Mapped[int] = mapped_column(TINYINT(unsigned=True), nullable=False, default=0)
    status: Mapped[str] = mapped_column(String(20), nullable=False, default="published")
    topic_id: Mapped[int | None] = mapped_column(BigInteger)
    like_count: Mapped[int] = mapped_column(Integer(unsigned=True), nullable=False, default=0)
    comment_count: Mapped[int] = mapped_column(Integer(unsigned=True), nullable=False, default=0)
    collect_count: Mapped[int] = mapped_column(Integer(unsigned=True), nullable=False, default=0)
    deleted: Mapped[int] = mapped_column(TINYINT(1), nullable=False, default=0)
    created_at: Mapped[datetime] = mapped_column(DateTime(3), server_default=func.now())
    updated_at: Mapped[datetime] = mapped_column(DateTime(3), server_default=func.now(), onupdate=func.now())

    images: Mapped[list["PostImage"]] = relationship(back_populates="post", lazy="selectin")
```

> 统一在 `app/db/base.py` 里设置 `naming_convention`，保证 Alembic 自动生成的约束名稳定。

## 6. 索引与查询对应

| 场景 | 查询 | 索引 |
|---|---|---|
| 推荐流 | `status='published' AND deleted=0 ORDER BY created_at DESC LIMIT 10` | `idx_status_created` |
| 关注流 | `JOIN follows ON followee_id=user_id WHERE follower_id=?` | `uk_follow` + `idx_user` |
| 话题流 | `post_topics WHERE topic_id=?` 再按时间/热度 | `idx_topic` |
| 帖子图片 | `post_images WHERE post_id IN (...)` | `idx_post` |
| 评论列表 | `comments WHERE post_id=? AND parent_id=0 ORDER BY created_at DESC` | `idx_post` |
| 是否已赞 | `likes WHERE user_id=? AND target_type=? AND target_id=?` | `uk_user_target` |
| 我的收藏 | `collections WHERE user_id=? AND target_type=? ORDER BY created_at DESC` | `idx_user_type` |
| 搜索 | `LIKE '%q%'`（数据量小时可接受） | 后续加全文索引 |

## 7. Alembic 迁移

```
alembic/
├── env.py                     # 读 app.core.config.settings.database_url
├── script.py.mako
└── versions/
    ├── 0001_init.py           # 17 张表
    └── 0002_indexes.py        # 冗余索引与唯一约束补充
```

| 命令 | 用途 |
|---|---|
| `alembic revision --autogenerate -m "msg"` | 生成迁移 |
| `alembic upgrade head` | 升到最新 |
| `alembic downgrade -1` | 回退一步（发布回滚用） |
| `alembic current` | 查看当前版本 |
| `alembic history` | 查看链路 |

**规则**
1. 每个迁移必须能 `downgrade`（不可逆操作要在注释里写明）。
2. 上线流程：备份 → `upgrade head` → 健康检查 → 观察。
3. 禁止在迁移里写业务数据修补（用单独脚本 `scripts/backfill_*.py`）。
