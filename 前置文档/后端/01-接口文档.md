## 1. 通用约定

```json
{ "code": 0, "message": "ok", "data": {}, "requestId": "8f3c1a2b9d4e" }
```

| 项 | 规则 |
|---|---|
| camelCase | 响应全部 camelCase（Pydantic `alias_generator=to_camel`） |
| ID | 字符串输出（`"100001"`） |
| 时间 | `YYYY-MM-DD HH:mm:ss`，Asia/Shanghai |
| 空值 | 字符串 `""`、数组 `[]`、对象 `null` |
| 列表 | `data` 必为对象：`{list, hasMore}` 或 `{list, total, page, size, hasMore}` |
| 请求体 | JSON；上传为 multipart |
| 长度单位 | 字数按 Unicode 字符计（Python `len(str)`） |

### 1.1 鉴权等级

| 标记 | 含义 |
|---|---|
| 免 | 无需 token |
| 可选 | 带 token 时返回个人化字段（`liked/collected/followed/isAuthor`），不带也能访问 |
| 必须 | 无 token → 401 `40101` |

### 1.2 错误码

| code | HTTP | 场景 |
|---|---|---|
| 0 | 200 | 成功 |
| 40001 | 400 | 参数缺失/类型错误/枚举非法 |
| 40101 | 401 | token 缺失、过期、签名错 |
| 40301 | 403 | 越权（非本人删除、不可见内容） |
| 40401 | 404 | 资源不存在或已删除/下架 |
| 40901 | 409 | 重复操作/重复提交 |
| 42201 | 422 | 业务校验失败（字数、范围、数量） |
| 42901 | 429 | 触发限流 |
| 50000 | 500 | 未捕获异常 |
| 50300 | 503 | DB/存储不可用 |

## 3. 认证

### A01 微信登录

`POST /auth/wechat-login` ｜ 免

| 参数 | 类型 | 必填 | 校验 |
|---|---|---|---|
| code | string | 是 | 1–128 字符；开发环境支持 `mock_<openid>` 形式 |

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiJ9...",
    "expiresIn": 604800,
    "isNewUser": true,
    "user": {
      "id": "100001", "nickname": "", "avatar": "", "gender": "secret",
      "birthday": null, "city": "", "bio": "", "wechatId": "jh_100001",
      "profileVisibility": "self", "createdAt": "2026-11-04 10:12:00",
      "completeness": { "filled": 0, "total": 7, "missing": ["avatar","nickname","gender","height","weight","goals","bio"] }
    }
  },
  "requestId": "8f3c1a2b9d4e"
}
```

| 错误 | 场景 |
|---|---|
| 40001 | code 为空 |
| 40101 | code 无效/已使用（`errcode 40029`） |
| 50000 | 微信接口不可达 |

**实现要点**：调用 `https://api.weixin.qq.com/sns/jscode2session`，拿到 `openid`；`session_key` **不落库、不返回**；按 openid upsert 用户；签发 JWT。详见 `06-微信登录流程说明.md`。

## 4. 用户

### A02 当前用户

`GET /users/me` ｜ 必须 → `data` 为 `User` 完整对象（含 `completeness`、`postCount/likeCount/followCount`）。401 时前端触发静默重登。

### A03 保存基本资料

`PUT /users/me/profile`

| 参数 | 类型 | 必填 | 校验 | 错误文案 |
|---|---|---|---|---|
| nickname | string | 否 | 2–20 字符，非纯数字，禁 `<>\/` | 昵称需 2–20 个字符 |
| avatar | string | 否 | http(s) URL，长度 ≤512 | 头像地址不合法 |
| gender | string | 否 | `male/female/secret` | 性别取值非法 |
| birthday | string | 否 | `YYYY-MM-DD`，≤ 今日，年龄 ≥12 | 请选择正确的出生日期 |
| city | string | 否 | ≤64 字符，格式 `省/市` | 请选择所在城市 |
| bio | string | 否 | ≤30 字 | 简介最多 30 字 |

> 只更新传入字段（partial update），未传字段保持不变。

```json
{ "code": 0, "data": { "user": { "...": "同 A02" }, "completeness": { "filled": 5, "total": 7, "missing": ["height","weight"] } } }
```

### A04 身体档案

`GET /users/me/body-profile`

```json
{ "code": 0, "data": {
  "height": 175, "weight": 68.0,
  "goals": ["recovery","posture","endurance"],
  "frequency": "3-4", "level": "intermediate",
  "focusParts": ["knee","calf"],
  "injuries": "", "allowPublic": false
} }
```

`PUT /users/me/body-profile`

| 参数 | 类型 | 校验 |
|---|---|---|
| height | int | 100–250 |
| weight | float | 30.0–200.0，1 位小数 |
| goals | array[str] | 1–3 项，取值 `fat_loss/muscle/recovery/posture/post_op/endurance` |
| frequency | str | `1-2/3-4/5+/irregular` |
| level | str | `beginner/intermediate/advanced` |
| focusParts | array[str] | ≤6，`neck_shoulder/lower_back/hip/knee/calf/foot` |
| injuries | str | ≤100 字 |
| allowPublic | bool | — |

返回 `{ bodyProfile, completeness }`。

### A05 完善度

`GET /users/me/completeness` → `{ "filled": 4, "total": 7, "missing": ["height","weight","bio"] }`

**算法（服务端唯一）**：头像、昵称、性别（非 `secret`）、身高、体重、运动目标、简介 —— 七项非空各计 1。

### A06 他人主页

`GET /users/{id}` ｜ 可选

```json
{ "code": 0, "data": {
  "id": "100001", "nickname": "运动达人", "avatar": "",
  "bio": "每周三次，专注下肢恢复", "city": "广东省/深圳市",
  "joinedDays": 12, "postCount": 12, "likeCount": 34000, "followCount": 56,
  "followed": false
} }
```

**隐私裁剪**：`profileVisibility=self` 时不返回 `bio/city/birthday`，仅昵称头像与统计；`bodyProfile` 永不对外返回。

### A07 他人动态

`GET /users/{id}/posts?page=1&size=12` → `{ list: [{id, coverImage, content(前 40 字), imageCount, likeCount, createdAt}], total, hasMore }`

## 5. 社区

### A08 信息流

`GET /feed?type=recommend|follow|latest&cursor=&size=10` ｜ 可选

| 参数 | 默认 | 说明 |
|---|---|---|
| type | recommend | `follow` 需登录（未登录返回 401） |
| cursor | "" | 上一页最后一条 ID（不透明） |
| size | 10 | ≤30 |

```json
{ "code": 0, "data": {
  "list": [{
    "id": "1",
    "author": { "id": "100001", "nickname": "运动达人", "avatar": "" },
    "followed": false,
    "content": "跑完 10 公里，小腿硬得像石头。今天用泡沫轴滚了 15 分钟，明显松了很多。",
    "images": [{ "url": "", "width": 1200, "height": 900 }],
    "topics": [{ "id": "1", "name": "跑后拉伸挑战" }],
    "visibility": "public", "status": "published",
    "likeCount": 128, "commentCount": 24, "collectCount": 36,
    "liked": false, "collected": false, "isAuthor": false,
    "createdAt": "2026-11-03 07:41:00"
  }],
  "nextCursor": "1", "hasMore": true
} }
```

**过滤规则**：只返回 `status='published' AND deleted=0`；`visibility='followers'` 的帖子仅作者与其关注者可见。

### A09 帖子详情

`GET /posts/{id}` ｜ 可选 → 单条（结构同 A08 的 item + `topics` 全量）。

| 情况 | 返回 |
|---|---|
| `published` | 200 |
| `hidden`/`deleted` 且非作者 | 40401 |
| `hidden`/`deleted` 且作者 | 200 + `status` 标明 |
| id 非法 | 40001 |

### A10 发布

`POST /posts` ｜ 必须

| 参数 | 类型 | 校验 |
|---|---|---|
| content | string | ≤500 字；与 images 不能同时为空 |
| images | array[str] | ≤9 个 URL（须为本站上传返回的地址） |
| topicIds | array[str] | ≤3 个，须存在 |
| visibility | string | `public/followers`，默认 public |

```json
{ "code": 0, "data": { "post": { "id": "13", "status": "published", "createdAt": "2026-11-04 11:00:00" } } }
```

| 规则 | 说明 |
|---|---|
| 审核策略 | **先发后审**：入库 `status='published'` |
| 敏感词 | 命中 → 42201「内容包含不适合发布的信息」 |
| 去重 | 同用户 10 秒内相同 content+images → 40901 |
| 限流 | 5 次/小时 |
| 话题计数 | 事务内 `post_count += 1`、`user_count` 由任务回写 |

### A11 删除帖子

`DELETE /posts/{id}` ｜ 必须 → 仅作者；软删 `deleted=1, status='deleted'`；事务内话题 `post_count -= 1`。返回 `{ "deleted": true }`。

### A12 点赞/取消

`POST /posts/{id}/like` ／ `DELETE /posts/{id}/like`

```json
{ "code": 0, "data": { "liked": true, "likeCount": 129 } }
```

- 幂等：已赞再赞返回 `code 0` + 当前状态（不报 409）；
- 计数并发安全：`UPDATE posts SET like_count = like_count + 1 WHERE id=?`；
- 点赞记录唯一约束 `(user_id, target_type, target_id)`。

### A13 收藏/取消

同 A12 结构，`{ collected, collectCount }`；写入 `collections(target_type='post')`。

### A14 评论列表

`GET /posts/{id}/comments?cursor=&size=20`

```json
{ "code": 0, "data": {
  "list": [{
    "id": "101",
    "user": { "id": "100002", "nickname": "康复小林", "avatar": "" },
    "content": "同款酸痛，收藏了",
    "parentId": "0", "replyToUser": null,
    "likeCount": 12, "liked": false, "isAuthor": false,
    "createdAt": "2026-11-03 09:02:00",
    "children": [
      { "id": "102", "user": { "id": "100003", "nickname": "夜跑阿凯", "avatar": "" },
        "content": "请问泡沫轴选硬的还是软的？", "parentId": "101",
        "replyToUser": { "id": "100002", "nickname": "康复小林" },
        "likeCount": 5, "liked": false, "isAuthor": false,
        "createdAt": "2026-11-03 09:20:00" }
    ]
  }],
  "nextCursor": "101", "hasMore": false
} }
```

**规则**：只返回一级评论分页；每条 `children` 最多 3 条（时间正序）；`replyCount` 可另给（前端显示「共 N 条回复」）。

### A15 发评论 / 回复

`POST /posts/{id}/comments` ｜ 必须

| 参数 | 类型 | 校验 |
|---|---|---|
| content | string | 1–200 字，非空白 |
| replyToId | string | 可选；存在则为回复，继承其 `parentId` |

返回 `{ comment, commentCount }`。限流 20 次/小时；5 秒内相同内容 → 40901。

### A34 评论点赞（1.0 新增）

`POST /comments/{id}/like` ／ `DELETE /comments/{id}/like` → `{ "liked": true, "likeCount": 13 }`

### A35 删除自己的评论（1.0 新增）

`DELETE /comments/{id}` → 仅作者；级联删除其回复（`parent_id=id`）；帖子 `comment_count -= (1 + 回复数)`；返回 `{ "deleted": true }`。

### A32 关注 / 取关

`POST /follows/{userId}` ／ `DELETE /follows/{userId}` → `{ "followed": true, "followCount": 57 }`

| 错误 | 场景 |
|---|---|
| 42201 | 关注自己 |
| 40401 | 用户不存在 |
| 40901 | 已关注（前端视为成功） |

## 6. 话题

| 编号 | 接口 | 参数 | 返回要点 |
|---|---|---|---|
| A16 | `GET /topics/hot?limit=10` | limit ≤20 | `{list:[{id,name,description,userCount,postCount,isHot}]}`，按 `sort DESC` |
| A17 | `GET /topics?page=1&size=12` | — | 分页话题，`hasMore/total` |
| A18 | `GET /topics/{id}` | — | 详情 + `collected`；40401 不存在 |

A16 示例：

```json

    "userCount": 12000, "postCount": 34000, "isHot": true }
] } }
```

### A29 全局搜索

`GET /search?q=&type=all|post|course|product&page=1`

```json
{ "code": 0, "data": {
  "courses": [ { "id": "1", "title": "下肢恢复训练计划", "cover": "", "duration": 1080, "difficulty": "beginner" } ],
  "products": [ { "id": "1", "name": "空气压力波按摩仪", "cover": "", "tagline": "专业腿部放松恢复" } ],
  "posts": [ { "id": "1", "content": "…", "coverImage": "", "author": { "id": "100001", "nickname": "运动达人" } } ],
  "counts": { "post": 6, "course": 2, "product": 2 }
} }
```

| 规则 | 说明 |
|---|---|
| q | 1–30 字，去首尾空格；为空 → 40001 |
| `type=all` | 每组 2 条 + `counts` |
| 指定 type | 只返回该组并分页 |
| 匹配 | `content LIKE`、`course.title/intro LIKE`、`product.name/tagline LIKE`；标题命中优先排序 |

## 10. 上传

### A30 头像

`POST /upload/avatar` ｜ 必须 ｜ `multipart/form-data`，字段 `file`

| 校验 | 值 |
|---|---|
| 类型 | `image/jpeg`、`image/png`、`image/webp` |
| 大小 | ≤5MB |
| 处理后 | 裁 512×512，质量 85，≤120KB |
| 存储 | `/data/upload/avatar/{yyyy}/{mm}/{uuid}.jpg` |

```json
{ "code": 0, "data": { "url": "https://cdn.jianheng.example.com/avatar/2026/11/8f3c.jpg", "width": 512, "height": 512 } }
```

### A31 动态图片

`POST /upload/images` ｜ 必须 ｜ 字段 `files`（可多个）

| 校验 | 值 |
|---|---|
| 单次 | ≤9 张 |
| 单张 | ≤5MB，类型同上 |
| 处理 | 最长边 2048 内不缩放；生成缩略图 640 |

```json
{ "code": 0, "data": { "urls": ["https://cdn.jianheng.example.com/post/2026/11/a.jpg"] } }
```

| 错误 | 场景 |
|---|---|
| 40001 | 未带文件 / 字段名错 |
| 42201 | 超过 9 张、类型不符、超出大小 |
| 50300 | 存储不可写 |

## 11. 埋点与系统

### A33 埋点 / 错误上报

`POST /track` ｜ 可选（未登录也接受）

```json
{ "event": "post_like", "props": { "post_id": "1", "action": "on" }, "page": "pages/community/index" }
```

| 规则 | 说明 |
|---|---|
| 白名单 | 只接受 PRD 第 8 节的 12 个事件名 + `app_error`/`api_error` |
| 大小 | `props` ≤2KB |
| 落库 | `track_events`；异步写，失败不影响响应 |
| 节流 | 同 IP+event 每秒 ≤20 条，超出丢弃（仍返回 200） |

返回 `{ "code": 0, "data": null }`。

### A36 健康检查

`GET /healthz`（不带 `/api/v1`）

```json
{ "status": "ok", "db": "ok", "version": "1.0.0", "time": "2026-11-04 16:00:00" }
```

DB 不通时返回 503 + `{"status":"degraded","db":"error"}`。
