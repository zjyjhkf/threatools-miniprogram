## 三句话基线

1. **1.0 不新增业务页面**：22 个业务页 + 1 个纯文本协议页 = 23 页面 / 19 路由；33 张设计稿全部沿用，视觉不变。1.0 的增量是"从 Mock 换成真实后端 + 微信登录 + 上传 + 埋点 + 可上线"。
2. **底部 2 页签、顶部 3 页签**，不可变更；「发现」是单页三容器（`pages/community/index` + 3 个 pane）。
3. **红线不可破**：不出现价格、购物车、下单、支付、设备连接、训练报告、客服、会员、优惠券、活动专区。

## 与 0.1 文档的关系

本目录**取代** 0.1 时期的《健衡运动社区-0.1 开发前置文档包》。0.1 的视觉令牌、组件编号、页面结构仍然有效并被继承；被修订的部分（技术栈、后端形态、接口数量、审核策略）在 `01-PRD.md` 第 2 节集中列出，不散落。
