# 健衡运动社区 · 1.0 UI 样式规则

| 项 | 内容 |
|---|---|
| 文档编号 | JH-FE-UI-1.0 |
| 版本 | 1.0 |
| 依据 | 33 张设计稿（750×1624 @2x）+ 0.1 已落地的 `styles/tokens.wxss` |
| 作用 | 前端样式的唯一依据；codebuddy 生成 WXSS 时必须遵守 |

---

## 1. 三条原则

1. **令牌唯一**：颜色、字号、间距、圆角、阴影只能引用 CSS 变量，WXSS 内不得出现裸十六进制（除 `rgba` 阴影）。
2. **不发明结构**：页面区块顺序与高度以 `02-页面清单与导航关系图.md` 与设计稿为准，不得"优化"布局。
3. **组件优先**：同类 UI 必须先查 23 个组件，能复用就复用，不得为单个页面复制一套卡片。

## 2. 设计令牌（`styles/tokens.wxss`）

```css
page {
  /* 品牌 */
  --brand-600: #2F6BFF;  --brand-700: #1E4FD8;  --brand-100: #E8F0FF;
  --brand-grad: linear-gradient(135deg, #2F6BFF, #5B9BFF);
  --accent-600: #FF6B35;  --success-600: #22C55E;
  --warning-600: #F59E0B; --danger-600: #EF4444;
  /* 文字 */
  --ink-900: #101828; --ink-700: #344054; --ink-500: #667085; --ink-400: #98A2B3;
  /* 背景与线 */
  --line-200: #E4E7EC; --bg-page: #F5F7FA; --bg-card: #FFFFFF;
  --bg-input: #F2F4F7; --bg-skeleton: #EEF0F3; --bg-mask: rgba(16,24,40,.45);
  --bg-warn: #FEF3C7;  --ink-warn: #B45309;
  /* 深色（C03/S05） */
  --dark-1: #000000; --dark-2: #0B0F16; --dark-3: #141821; --dark-4: #0B1B33;
  /* 字阶 */
  --fs-h1: 48rpx; --fs-h2: 40rpx; --fs-h3: 34rpx; --fs-body: 28rpx;
  --fs-body-s: 26rpx; --fs-caption: 24rpx; --fs-micro: 20rpx;
  /* 圆角 / 阴影 / 间距 */
  --r-s: 16rpx; --r-m: 24rpx; --r-l: 32rpx; --r-full: 999rpx;
  --sh-card: 0 8rpx 24rpx rgba(16,24,40,.06);
  --sh-float: 0 12rpx 32rpx rgba(16,24,40,.12);
  --page-pad: 32rpx; --card-gap: 24rpx; --block-gap: 40rpx;
}
```

| 类别 | 规则 |
|---|---|
| 颜色 | 只用上表变量；渐变只用于头部/主按钮/Banner/FAB，面积 ≤25% |
| 字阶 | H1 48/64 700、H2 40/56 600、H3 34/48 600、Body 28/44 400、Body-S 26/40、Caption 24/34、Micro 20/28 |
| 字重 | 仅 400/600/700 |
| 间距 | 只用 8 的倍数：8/16/24/32/40/48/64/80；页面左右 32；卡片间距 24；区块间距 40 |
| 圆角 | 仅 16/24/32/999 四档 |
| 阴影 | 只有 `--sh-card`、`--sh-float` 两种 |
| 描边 | 1rpx `--line-200`；错误态 2rpx `--danger-600` |
| 层级 | z-index 只用 1/10/100/1000 |

## 3. 页面骨架

```html
<view class="pg">
  <nav-bar title="运动社区" show-search bind:search="onSearch" />
  <top-tabs tabs="{{tabs}}" current="{{tab}}" bind:change="onTabChange" />
  <view class="pg-body"><!-- scroll-view / swiper --></view>
  <fab-publish wx:if="{{tab === 0}}" bind:tap="onPublish" />
  <toast show="{{toast.show}}" text="{{toast.text}}" />
  <dialog show="{{dialog.show}}" ... />
</view>
```

```css
.pg { display: flex; flex-direction: column; height: 100vh; background: var(--bg-page); }
.pg-body { flex: 1; min-height: 0; }         /* 关键：避免 flex 子项撑破 */
.pg-scroll { height: 100%; }
```

| 页面类型 | 高度构成 |
|---|---|
| 一级（带页签 + TabBar） | 状态栏 88 + 导航 88 + 页签 96 + 内容 + TabBar 98 + 指示条 68 |
| 二级（仅导航） | 状态栏 88 + 导航 88 + 内容 |
| 弹层页 | 内容 + 遮罩 + 底部弹层（`padding-bottom: env(safe-area-inset-bottom)`） |

**规则**：`scroll-view` 必须给确定高度（JS 算 px 或 `flex:1 + min-height:0`）；不要让内容把页面撑出屏幕。

## 4. 组件样式规则

### 4.1 按钮

| 类型 | 样式 |
|---|---|
| 主按钮 | 高 88，圆角 999，`--brand-grad` 底，白字 32/600 |
| 次按钮 | 高 88，圆角 999，透明底 + 1rpx `--brand-600` 描边 + 蓝字 |
| 文字按钮 | 28/600 `--brand-600`，无底无边框，点击区 ≥88×88 |
| 危险按钮 | 底部对话框内：`--danger-600` 实心 + 白字 |
| 禁用 | `--bg-input` 底 + `--ink-400` 字 + 无阴影；**不降透明度**（保持可读） |
| 状态 | 默认 / 按下（`opacity:.85` 或更深一档）/ 加载（文字替换 + 禁用） |

### 4.2 卡片

```css
.card {
  background: var(--bg-card);
  border-radius: var(--r-m);
  box-shadow: var(--sh-card);
  margin: 0 var(--page-pad) var(--card-gap);
  overflow: hidden;                 /* 图片出血时用 */
}
```

- 卡片**不描边**，只用投影；
- 图片在卡片内出血到左右边（`margin: 0 -32rpx` 或父级 padding 0）；
- 卡片内文字边距统一 32；
- 需要上浮（M02/D04/D10）时用负 margin，**父级不得 `overflow:hidden`**。

### 4.3 表单行

| 元素 | 规格 |
|---|---|
| 行高 | 104；左右 32 |
| 标签 | 28/400 `--ink-700`，宽 200 |
| 值 | 28/400 `--ink-900`，右对齐；占位 `--ink-400` |
| 未填写 | 值用 `--accent-600`（橙色），文案「未填写」 |
| 箭头 | 28×28 `--ink-400`，右边距 32 |
| 分割线 | 1rpx `--line-200`，左侧从 64 开始（对齐标签） |
| 错误 | 输入框 2rpx `--danger-600` + 下方 24rpx 红字提示 + 16 图标 |

### 4.4 列表与网格

| 模式 | 规格 | 用于 |
|---|---|---|
| 单列卡片流 | 686 宽，间距 24 | D01/D04 |
| 两列网格 | `grid-template-columns: repeat(2, 1fr); gap: 24rpx` | P01 |
| 两列瀑布 | 高度自适应，列间距 16 | D10 |
| 三列九宫格 | 218×218，间距 8 | 帖子多图 |
| 横滑 | `scroll-x` + `white-space: nowrap`，卡间 16 | 相关课程/产品 |
| 列表行 | 高 104/112，底部 1rpx 分割线 | 设置、资料 |

### 4.5 弹层

| 类型 | 规格 |
|---|---|
| 遮罩 | `rgba(16,24,40,.45)`，全屏，点击可关（评论输入除外） |
| 底部弹层 | 白底，顶部圆角 32，把手 80×8，`padding-bottom: env(safe-area-inset-bottom)`，上滑 300ms |
| 对话框 | 600 宽，圆角 24，标题 34/600 + 描述 26/44 + 双按钮 88 高 |
| 层级 | 遮罩 1000，内容 1001；`textarea` 在弹层打开时隐藏或降级为 `view` |

### 4.6 空态 / 错误 / 骨架

| 类型 | 规格 |
|---|---|
| 空态 | 插图 200×200 + 主文案 34/600 + 副文案 26 `--ink-500` + 可选按钮 |
| 错误 | 同上，插图换 `--danger-600` 描边图标，按钮「重试」 |
| 断网条 | 高 64，`--bg-warn` 底，`--ink-warn` 字 24，顶部固定 |
| 骨架 | 块 `--bg-skeleton`，圆角同目标，透明度 0.4↔1，1.2s 循环 |
| 加载更多 | 高 96，居中 24 `--ink-400`：加载中… / 没有更多了 / 加载失败，点击重试 |

## 5. 图标与图片

| 项 | 规则 |
|---|---|
| 图标 | iconfont 类名 `icon-xxx`，尺寸 48（列表/导航）/40（内联）/64（空态）/200（插图） |
| TabBar | 用 4 枚 PNG（81×81）避免字体闪烁 |
| 颜色 | 继承 `currentColor`，不单独写色值 |
| 图片 | `mode="aspectFill"` + 固定比例容器 + `lazy-load` |
| 占位 | 一律走 `image-ph` 组件（`--brand-100` 底 + 图标） |
| 比例 | 帖子 4:3 / 1:1；课程封面 16:9；产品 1:1；头像 1:1；Banner 16:7 |
| 禁止 | emoji 当图标、多色图标、拉伸变形、圆角混用 |

---

## 6. 适配与安全区

| 项 | 规则 |
|---|---|
| 单位 | 只用 rpx；1px 级边框用 1rpx |
| 状态栏 | `wx.getWindowInfo().statusBarHeight` 动态取，`nav-bar` 内置占位 |
| 底部 | `padding-bottom: env(safe-area-inset-bottom)`（iOS 34pt） |
| 小屏 | `@media (max-height: 700px)` 收紧纵向间距 10%，不缩字号 |
| 横屏 | `app.json` 不配置横屏；页面 `"pageOrientation": "portrait"` |
| 深色模式 | 1.0 锁定浅色，不跟随系统（M07 开关仅展示） |

## 7. 动效

| 场景 | 参数 |
|---|---|
| 页签切换 | 位移 + 透明度 250ms `ease-out` |
| 点赞 | 1→1.25→1，300ms |
| 收藏 | 填充 + 弹跳 200ms |
| 弹层 | 上滑 300ms `cubic-bezier(.2,.8,.2,1)`，遮罩淡入 200ms |
| Toast | 淡入 150ms，停留 1.5s，淡出 200ms |
| 骨架 | 1.2s 循环 |
| 页面转场 | 系统默认，不自定义 |

## 8. 禁止项（评审直接打回）

| # | 禁止 | 正确做法 |
|---|---|---|
| 1 | 裸十六进制色值 | 用 `var(--brand-600)` |
| 2 | 圆角 20/28/36 | 只用 16/24/32/999 |
| 3 | 正文字号 <24rpx | 正文 28，最小 24 |
| 4 | 满屏渐变 | 渐变只做头部/按钮/Banner |
| 5 | 卡片描边 + 阴影同时用 | 二选一（默认只用阴影） |
| 6 | 三个字重以上 | 400/600/700 选其二 |
| 7 | `!important` 覆盖 | 提升选择器或改组件属性 |
| 8 | 图片不设比例 | 固定容器比例 + `aspectFill` |
| 9 | 按钮用 `view` 无热区 | 点击区 ≥88×88rpx |
| 10 | 深色页混用浅色卡片 | C03/S05 用 `--dark-*` 系列 |
| 11 | 出现价格/购物车/客服等 0.1 红线元素 | 见 `01-PRD` 1.1 |
| 12 | 自造弹层替代 `picker-sheet/dialog` | 复用组件 |

## 9. 样式审查清单

- [ ] 页面只有 `--bg-page` 底，卡片只有 `--bg-card`
- [ ] 所有颜色/字号/间距/圆角均来自令牌（全局搜索 `#` 十六进制应为 0 处，除 tokens.wxss）
- [ ] 三个页签页签栏 96 高，文字 30/600，下划线 48×6
- [ ] TabBar 98 + 安全区，图标 48，文字 20
- [ ] 卡片间距 24，页面边距 32，区块间距 40
- [ ] 正文 ≥24rpx，行高 44
- [ ] 图片全部有比例容器与占位
- [ ] 表单行高 104，标签宽 200，未填写橙色
- [ ] 弹层遮罩 `rgba(16,24,40,.45)`，底部圆角 32
- [ ] 空态/错误/骨架三态样式与 `empty-state`/`skeleton` 一致
- [ ] iPhone SE 上无横向滚动、无文字截断
- [ ] 深色页（C03/S05）色阶为 `#000/#0B0F16/#141821`
