## 2. 统一响应包

```json
{
  "code": 0,
  "message": "ok",
  "data": { },
  "requestId": "8f3c1a2b9d4e"
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| code | int | 0 = 成功；非 0 见第 6 节 |
| message | string | 面向用户可读的中文提示（前端可直接 Toast） |
| data | object \| array \| null | 业务数据；成功但无数据时为 `null` |
| requestId | string(16) | 每次请求唯一；同时写入响应头 `X-Request-Id` |

**硬规则**
1. 任何响应都必须带 `requestId`（含 4xx/5xx）。
2. `data` 为列表时必须返回对象（`{list, hasMore, ...}`），**不得直接返回数组**。
3. 不得返回 `null` 的 `data` 后再让前端判空——列表用 `[]`。
4. 错误响应 `data` 固定 `null`，细节放 `message`，可另带 `data.detail`（仅调试环境）。

## 3. 鉴权

| 项 | 约定 |
|---|---|
| 头 | `Authorization: Bearer <JWT>` |
| 算法 | HS256，密钥仅服务端 |
| 有效期 | 7 天（`exp`） |
| Claims | `sub`(userId 字符串)、`openid`、`role`(user/admin)、`typ`(access)、`iat`、`exp`、`jti` |
| 免鉴权接口 | `POST /auth/wechat-login`、`GET /healthz`、`GET /feed`、`GET /posts/{id}`、`GET /topics*`、`GET /courses*`、`GET /products*`、`GET /search`、`GET /users/{id}`、`GET /users/{id}/posts` |
| 可选鉴权 | 上述免鉴权接口若带 token，则返回 `liked/collected/followed` 等个人化字段；不带时返回 `false` |
| 401 语义 | token 缺失/过期/签名错误，一律 401 + `code=40101` |
| 前端处理 | 静默重登 1 次 → 仍失败跳登录页 |

> **可选鉴权**是 1.0 的关键设计：游客浏览列表也要能拿到 `likeCount`，登录用户要拿到 `liked`。后端用同一接口按 token 有无分支，不新增两套接口。

## 4. 命名与类型

| 项 | 约定 |
|---|---|
| JSON 字段 | **camelCase**（`likeCount`、`createdAt`） |
| 数据库字段 | snake_case（`like_count`、`created_at`） |
| 映射位置 | 后端 Pydantic `alias_generator=to_camel` + `populate_by_name=True`；不在前端做转换 |
| ID | **字符串**（`"100001"`），避免 JS 精度丢失；后端 BIGINT → str |
| 时间 | `"YYYY-MM-DD HH:mm:ss"`，无时区后缀，无毫秒 |
| 时间戳 | 不使用；分页游标除外（游标是不透明字符串） |
| 布尔 | `true/false`，字段名以 `is/has/can/allowed` 开头（`liked`、`hasMore`、`allowPublic`） |
| 枚举 | 小写下划线字符串（`fat_loss`、`neck_shoulder`、`beginner`） |
| 空值 | 字符串用 `""`，数组用 `[]`，对象用 `null`；**不使用 `undefined`** |
| 金额 | 1.0 无金额字段 |
| 数量 | 非负整数；超过 1 万前端格式化为「1.2 万」 |

## 5. 分页与排序

### 5.1 游标分页（信息流、评论、话题下帖子）

请求：`?cursor=&size=10`（`cursor` 为空表示第一页；`size` 默认 10，最大 30）

```json
{ "code": 0, "data": { "list": [], "nextCursor": "1", "hasMore": true } }
```

- `nextCursor` 不透明，前端原样回传，**不得解析**；
- `hasMore=false` 时 `nextCursor=""`；
- 排序在服务端固定（信息流：`created_at DESC`；话题下帖子：`hot=like_count DESC` / `new=created_at DESC`）。

### 5.2 页码分页（话题、课程、收藏、搜索、用户动态）

请求：`?page=1&size=10`

```json
{ "code": 0, "data": { "list": [], "total": 128, "page": 1, "size": 10, "hasMore": true } }
```

### 5.3 通用规则

| 规则 | 说明 |
|---|---|
| `size` 上限 | 30，超出按 30 处理 |
| `page` 越界 | 返回空 `list` + `hasMore=false`，不报错 |
| 空结果 | 200 + 空列表，不返回 404 |
| 排序参数 | 只接受白名单值（`hot/new`），非法值回落默认 |

## 6. 错误码

| code | HTTP | 含义 | 前端动作 |
|---|---|---|---|
| 0 | 200 | 成功 | — |
| 40001 | 400 | 参数错误 | Toast `message`（后端中文） |
| 40101 | 401 | 未登录/过期 | 静默重登 1 次 |
| 40301 | 403 | 无权限 | Toast「没有权限」 |
| 40401 | 404 | 资源不存在/不可见 | 页面「内容不存在」态 |
| 40901 | 409 | 重复操作（已点赞等） | 视为成功，不报错 |
| 42201 | 422 | 业务校验失败 | Toast `message` + 表单定位 |
| 42901 | 429 | 频率限制 | Toast「操作太频繁，请稍后再试」 |
| 50000 | 500 | 服务异常 | 错误态 + 重试；上报 `api_error` |
| 50300 | 503 | 依赖不可用（DB/存储） | 同上，文案「服务维护中」 |

**文案来源**：前端**不硬编码**业务错误文案，直接展示 `message`；只有网络层错误用本地文案（`网络开小差了`）。

## 9. 上传协议

### A30 头像

```
POST /upload/avatar
Content-Type: multipart/form-data
Authorization: Bearer <token>
file: <binary>          # jpg/png/webp，≤5MB
```

```json
{ "code": 0, "data": { "url": "https://cdn.jianheng.example.com/avatar/8f3c.jpg", "width": 512, "height": 512 } }
```

- 服务端裁 512×512、质量 85，落地 ≤120KB；
- 文件名 UUID，扩展名按 MIME 推断；
- 返回**绝对 HTTPS URL**。

### A31 动态图片

```
POST /upload/images
files: <binary>（可多个同名字段）
```

```json
{ "code": 0, "data": { "urls": ["https://...", "https://..."] } }
```

| 规则 | 值 |
|---|---|
| 单次最多 | 9 张 |
| 单张大小 | ≤5MB |
| 类型 | `image/jpeg`、`image/png`、`image/webp` |
| 前端并发 | 3 |
| 前端预处理 | 最长边 1440、质量 80（`wx.compressImage`） |
| 失败重试 | 1 次，仅重试失败项 |

## 10. 幂等与并发

| 场景 | 约定 |
|---|---|
| 点赞/收藏/关注 | 幂等：重复调用返回当前状态 + `code=0`（或 40901，前端都视为成功） |
| 发布 | **不幂等**：前端按钮 500ms 防抖 + loading 禁用；后端按 `content+images` 10 秒内去重（返回 40901） |
| 评论 | 同上，5 秒内相同内容去重 |
| 并发 401 | 前端只重登 1 次 |
| 并发上传 | 前端并发 3，后端无限制 |

## 11. Mock 与真实切换

| 模式 | 触发 | 行为 |
|---|---|---|
| Mock | `env.USE_MOCK=true` | 全走 `mock/index.js`，不发网络请求；数据写内存 |
| 混合 | `MOCK_ERROR={A08:50000}` | 指定接口注入错误，用于演示错误态 |
| 真实 | `USE_MOCK=false` | 走 `wx.request`，需后端可用 |

**一致性要求**：Mock 返回必须与本文档 DTO 完全一致（字段名、类型、嵌套），否则视为缺陷。`mock/index.js` 已有 32 接口实现，1.0 补 A34/A35/A36 与 `requestId` 占位字段。

## 13. 契约变更流程

| 变更类型 | 流程 |
|---|---|
| 新增可选字段 | 后端直接加，前端可忽略；通知前端一句 |
| 新增接口 | 先在本文档登记编号（从 A37 起顺延），再实现 |
| 修改字段名/类型 | **禁止**；改为新增字段 + 双写兼容一个版本 |
| 修改路径/方法 | **禁止**；新增 v2 路径 |
| 修改错误码语义 | 需前端确认，登记到第 6 节表格 |
| 删除字段 | 先标记废弃，一个版本后删除 |
