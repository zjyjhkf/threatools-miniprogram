## 4. 路由参数表

| 路由 | 参数 | 必填 | 类型 | 缺失/非法兜底 |
|---|---|---|---|---|
| `pages/community/index` | `tab` | 否 | `community\|course\|product` | 缺省 `community`；非法值忽略 |
| `pages/mine/index` | — | — | — | — |
| `login` | `redirect` | 否 | string（页面路径） | 缺省登录后 `switchTab` 到发现 |
| `search` | `type` | 否 | `all\|post\|course\|product` | 缺省 `all` |
| `doc` | `type` | 是 | `agreement\|privacy\|about` | 缺省显示协议；非法值同上 |
| `topics` | — | — | — | — |
| `topic-detail` | `id` | 是 | string | 缺失 → Dialog「参数缺失」+ 返回 |
| `post` | `id` | 是 | string | 同上；接口 404 → 「内容不存在」态 |
| `publish` | `topicId` | 否 | string | 无则空话题；非法 topicId 忽略 |
| `publish-result` | `status` | 否 | `pending\|success\|fail` | 缺省 `pending` |
| `user-profile` | `id` | 是 | string | 缺失 → 兜底返回 |
| `detail`(课程) | `id` | 是 | string | 404 → 「课程已下架」 |
| `play` | `id`,`chapter` | 是/否 | string/int | `chapter` 缺省 1；越界取第 1 节 |
| `detail`(产品) | `id` | 是 | string | 404 → 「该产品已下架」 |
| `profile` | — | — | — | 未登录 → 拦截登录 |
| `profile-edit` | `field` | 否 | 字段名 | 无则顶部开始；非法忽略 |
| `body-profile` | `field` | 否 | 字段名 | 同上 |
| `favorites` | `type` | 否 | `post\|course\|product` | 缺省 `post` |
| `settings` | — | — | — | — |

**深链规则**：分享只产生 3 类链接（`post?id=`、课程 `detail?id=`、产品 `detail?id=`）；`scene` 参数仅做归因，不入业务逻辑。

## 5. 分包与预加载

| 包 | 页面 | 体积预算 | 加载策略 |
|---|---|---|---|
| 主包 | community/index、mine/index、23 组件、公共层 | ≤1.7MB | 启动 |
| packageCommon | login、search、doc | ≤140KB | 按需 |
| packageCommunity | topics、topic-detail、post、publish、publish-result、user-profile | ≤430KB | 发现页 3s 后 preload |
| packageCourse | detail、play | ≤190KB | 课程页签激活时 preload |
| packageProduct | detail | ≤110KB | 产品页签激活时 preload |
| packageMine | profile、profile-edit、body-profile、favorites、settings | ≤280KB | 进入我的时 preload |

`app.json` 的 `preloadRule` 沿用 0.1 现状（community → packageCommunity，mine → packageMine），1.0 追加：

```json
"pages/community/index": { "network": "all", "packages": ["packageCommunity", "packageCourse", "packageProduct"] }
```

> 注意：一次预载多个分包会拉高流量，仅在 WiFi 下放开全部，`network` 用 `wifi` 时只预载 community。

## 6. 导航交互规则

| 编号 | 规则 |
|---|---|
| N-01 | `custom-tab-bar` 只能在 tab 页使用；每个 tab 页 `onShow` 必须 `getTabBar().setData({selected})` |
| N-02 | 三个顶部页签用 `swiper` 承载，切换不重建、保留各自 `scroll-view` 位置 |
| N-03 | 页签切换阈值：滑动超过 1/3 屏宽才切换（`swiper` 默认行为，不改） |
| N-04 | 返回栈上限 5 层，超出走 `navigateBack({delta:2})` |
| N-05 | `switchTab` 不会触发 `onLoad`，数据刷新放 `onShow` 并按 60s 节流 |
| N-06 | 重复点击 FAB/导航项做 500ms 防抖，避免连开两页 |
| N-07 | 详情页返回列表时，列表不重新请求（用 store 缓存 + 本地增量更新） |
| N-08 | 登录页使用 `navigateTo`（可返回），登录成功后 `navigateBack` 回到原页 |
